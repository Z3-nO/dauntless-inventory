Live connection · preview

Install once with Forever and Dauntless closed. Both versions include an optional native extension for automatic inventory and build refresh in single-player. Original loader and backend files are backed up. Native refresh follows the game directory configured in Forever; start it with the version folder’s 2 - PLAY.bat. Wait for server and client acknowledgement before another change. Reset, restore and adding slots remain offline.

Live module updates

Only signed releases from this project are installed. Updates wait until the game and Forever server are closed. The previous module is backed up and restored if installation fails.
